ALT TEXT FOR IMAGES

Put one plain text file here for each image you want to describe. The file name must be exactly the
same as the image name, with .txt instead of the picture ending:

  images/event-1-photo-1.webp   ->   alt/event-1-photo-1.txt
  images/portrait-3.webp        ->   alt/portrait-3.txt
  images/short-form-1-thumbnail.webp -> alt/short-form-1-thumbnail.txt  (used as the label of the play button)

Inside the file, write one short sentence saying what the picture shows, for example:

  Dancer in a red tracksuit holding a freeze on stage at Red Bull Dance Your Style

Tips: plain text only (no quotes needed), one or two sentences, up to about 300 characters.
Say what is in the picture, not "image of". Screen readers read this aloud and search engines use it.
Images without a text file keep an automatic description.
